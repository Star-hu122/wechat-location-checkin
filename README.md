# 微信小程序智能定位签到系统

## 项目简介

本项目是一个面向课程教学场景的微信小程序定位签到系统设计。教师可以导入学生名单、维护课程与上课安排、创建签到活动并设置签到地点；学生登录后可以查看自己的课程，在教师开启签到活动后完成定位签到。

## 当前设计内容

- 数据库表结构与 MySQL 8.0 SQL 文件
- 数据库表字段说明文档
- 数据库设计说明文档
- ER 图
- 交互界面原型

## 主要业务流程

1. 管理员登录并导入学生名单。
2. 创建课程、课程班和每周上课安排。
3. 为学生分配默认课程班，必要时授权替代课程班。
4. 教师创建签到活动，设置签到点和距离阈值。
5. 教师手动开启或关闭签到活动。
6. 学生选择课程，在活动开启期间提交定位签到。
7. 教师查看签到记录并导出结果。
